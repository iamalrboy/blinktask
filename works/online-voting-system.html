CASE STUDY / 02 · ACADEMIC PROJECT

Online voting.
Clearer user flows.

A student project exploring the flow from voter interaction through vote submission and result handling.

i

Project status: Academic project. This page does not claim suitability for real elections or independently verified election security.

Design questions

  • How does a user understand the steps required to participate?
  • How should validation and error states be communicated?
  • How can the interface avoid accidental duplicate actions?
  • What should be visible to users after a submission?

Evaluation still required

Real election systems require independent security engineering, privacy analysis, accessibility testing, verifiable auditability, and appropriate legal and operational review. A classroom implementation is not evidence that these requirements have been met.

Evidence to add

  • Verified feature list and screenshots of the actual implementation.
  • Technology stack, testing approach, and personal contribution.
